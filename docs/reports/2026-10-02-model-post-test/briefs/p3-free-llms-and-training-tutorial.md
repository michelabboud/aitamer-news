TOPIC: a tutorial (about 1,500 words) with two parts. Part 1: the free and open-weight language models a developer can use today, grouped by type (for example base, instruction-tuned, reasoning, small on-device, code), with what each type is for and the licence terms to read before using one commercially. Part 2: how to train your own small model, as a realistic path from data to a working checkpoint using open tools, with the real costs and limits stated and a way to check that the result works.
