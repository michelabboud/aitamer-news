## Concerns and observations
Real runs exposed token-format assumptions, hidden bypass metadata, timezone formatting, rewritten check links and shallow deployment history. Those failures are retained in individual reports. Local mocked API proofs were insufficient for live acceptance; neither running services nor successful admission alone proved publication.

Older failed requests also exposed late closed-source checks and historical deployment scans. These final fixes prevent unnecessary polling. Existing grandfathered article-body findings and reader-text warning remain unchanged. No real ledger was written locally, no required check was bypassed, no user data or branch was deleted.
