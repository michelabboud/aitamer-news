## Assumptions made

Use a permission-free review notification plus the existing trusted finalizer and dispatch endpoint. The controller independently checks the server's exact owner review; notification payloads, labels, App identity and comments are not approval. Preserve the existing run/state/proof formats instead of introducing a queue or service. Owner-authored exceptional PRs retain owner dispatch because GitHub forbids self-approval. Numbering-only repairs preserve the original approved article set even when restored bytes disappear from the diff.
