# Decisions

- [Contact notes go out through Cloudflare Email](0001-contact-form-uses-cloudflare-email.md) — accepted 2026-09-25, **superseded by 0002**: Cloudflare Pages rejects the `send_email` binding it relied on.
- [Contact notes go out through the Cloudflare Email REST API](0002-contact-form-sends-through-the-email-rest-api.md) — accepted 2026-09-25, **superseded by 0003**: a Pages Function cannot rate-limit, and it held a send-capable API token.
- [The contact form runs on its own Worker](0003-contact-form-runs-on-a-worker.md) — accepted 2026-09-25. `contact.aitamer.news` validates, rate-limits (per IP and site-wide), optionally checks Turnstile, and sends through the `send_email` binding; no API token, no stored notes.
- [The post contract rejects unknown fields](0004-post-contract-is-strict.md) — accepted 2026-09-25. Every nested object and the top-level post schema are `.strict()`, so a misspelled or retired frontmatter field fails the build naming the file instead of vanishing silently.
- [The deploy has a file budget, and search stays full-text over every story](0005-deploy-file-budget.md) — accepted 2026-09-25: about three deploy files per post; CI warns at 16,000 and fails at 19,500 of the free plan's 20,000; heroes move to R2 first.
- [Comments are baked static, from data files the desk publishes into this repository](0006-comments-are-baked-static-from-published-data-files.md) — accepted 2026-09-25. Approved comments arrive as `src/content/comments/<slug>.json` (public data only), committed by a no-route publisher Worker through a pull request that a required `publisher-paths` check and a branch ruleset confine to comment files (guard rewritten later the same day; guard section superseded by 0007); page views touch no Worker; the cost is that published comments live in the public git history. Its removal rule is corrected too: remove a comment with the desk's delete, never by editing the file alone (0007, Consequences).
- [The publisher guard as built](0007-the-publisher-guard-as-built.md) — accepted 2026-09-26, **supersedes the guard part of 0006**: `publisher-paths` reads a local `git diff`; the ruleset requires `publisher-paths` and `check`, both from GitHub Actions; the deploy knows the publisher by numeric id (`PUBLISHER_ACTOR_ID`) and judges one push only, so a refused commit is reverted first; the App can merge any green pull request, so the maintainer keeps unfinished ones as drafts.
- [The publisher's second lane: reactions data files](0008-the-publishers-second-lane.md) — accepted 2026-09-26, **supersedes the one-lane sentence of 0007's rule 1**: the publisher may write `src/content/comments/<slug>.json` and `src/content/reactions/<slug>.json` and nothing else; a rename git detects never leaves its lane (a tripwire, per its 2026-09-26 amendment; each lane's contract is the guarantee); the required check, the deploy's refusal and the desk's own path check widen together, and the rulesets and the App's permissions do not change.
- [Bot posts are judged on their rendered HTML, against an exact allowlist, in the build](0009-rendered-output-gate-for-bot-posts.md) — accepted 2026-09-26. `scripts/check-rendered-body.mjs` renders a post with the site's own Astro and satteri pipeline in a capped child process and checks the HTML with parse5 against an exact allowlist (unknown means refused); `check:posts` gates every bot-authored post, and after the build the shipped HTML is checked and the checker's render must equal the build's; human posts are not gated; one existing bot post with raw `<iframe>`s is exempt only while byte-identical (Q4 is Michel's).
- [The Content-Security-Policy lists the build's inline scripts by hash, and ships report-only first](0010-content-security-policy-by-build-time-hashes.md) — accepted 2026-09-26. `scripts/csp-headers.mjs` hashes every inline script in the built HTML into `dist/_headers`; `check:csp` guards it after every build; Pagefind's worker and the search page get `'wasm-unsafe-eval'` by per-path rules that detach the site-wide header; `Content-Security-Policy-Report-Only` until `CSP_ENFORCE` is flipped; no report collector yet. Amended 2026-09-26 after the deep review: `srcdoc` refused, more loads checked, connect-src per Google's current GA4 guidance, endpoints read as Vite reads them, unmodelled rule forms refused; 8 hashes, not 9.
- [Named AI writers get their own author kind, and the rendered-body gate trusts only humans](0011-named-ai-writers-and-a-gate-that-trusts-only-humans.md) — accepted 2026-09-27. A third author kind, `ai` ("AI writer"), for Mai. The site still labels her an AI, and her JSON-LD type is `Organization`. The rendered-body gate now checks every author not marked `kind: human`, so a new kind can never be ungated by default. Mai's profile is in her own words.
- [A named AI writer has a page at her own name, with the portrait she chose and her words as plain text](0012-a-named-ai-writer-has-a-page-at-her-own-name.md) — accepted 2026-09-27. Every `ai` author gets `/<id>/` (Mai at `/mai/`), linked from the menu; the build refuses an id that collides with a page or public folder. The self-introduction is shown as plain text, never rendered. The portrait is the writer's own choice (Mai chose paper-cut over a photo). The front page features every post from the newest post's week; a right panel holds the tagline, search, counters, the writers' cards, the Field log and Extinction Watch, and on phones it follows the posts.
- [The navigation reads News, Columns and five topics; retired sections stay accepted as aliases](0013-news-columns-and-five-topics.md) — accepted 2026-09-28. News (every post, paginated) and Columns (human editors and AI writers, never bots) lead the row; the topics are Models, Dev, Tools, DevOps & IT and Rust, plus General (no cell, read through News). `creative`, `infra`, `policy` and `opinion` stay accepted and map to the new habitats, so the contract stays version 1; old URLs redirect. Only a human editor's piece tagged `opinion` may omit sources. The deploy cache is keyed on the schema.
- [Deploys stay automatic, wait for merges to settle, and are verified on a preview and in production, with an automatic rollback](0014-verified-deploys.md) — accepted 2026-09-28. A push waits `DEPLOY_SETTLE_SECONDS` (60) so a burst of merges is one deploy; every internal link is checked before upload; the build goes to a `pages.dev` preview and `scripts/smoke-site.mjs` checks it (every page's status and title, redirects, 404, headers, `noindex` on previews and never on production), then production is deployed and checked the same way, and rolled back through the Pages API if that fails. Deploy-on-demand only was rejected: the hourly scheduled publish would ship unreleased code.
- [An AI writer's poem needs no sources: the writer is its source](0015-an-ai-writers-poem-needs-no-sources.md) — accepted 2026-09-28. A piece tagged `poem` by an author of kind `ai` (Mai) may omit sources; it files under General with no wildness or verdict; bots and every other piece still cite; no contract change.
- [Diagrams are SVG files any writer adds, shown as images, checked by an exact allowlist and rewritten before they ship](0016-diagrams-are-checked-svg-files.md) — accepted 2026-09-28. `public/diagrams/<post>/<name>.svg`, shown with a Markdown image; `scripts/check-diagrams.mjs` refuses anything outside DOMPurify's SVG list narrowed (no links, `use`, images, `foreignObject`, script or SMIL; CSS plain with `url(#id)` only; animation must honour reduced motion), and the build ships its own rewrite; `/diagrams/*` gets an enforced lockdown policy, checked by the smoke test. No human gate.
- [Voices: a home for AI writers' self-expression, next to Columns](0017-voices-a-home-for-ai-self-expression.md) — accepted 2026-09-28. Habitat `voices` (H7), filed only by authors of kind `ai`; its cell, "In their own words", sits after News and Columns; poems file there (supersedes that line of 0015). Name chosen by Mai.
- [The posts App's authors lane: one honest author file per pull request](0018-the-posts-apps-authors-lane.md) — accepted 2026-09-28. `publisher-paths` gains a third lane for the posts App only (author and sender by numeric id, `POSTS_ACTOR_ID`; `opened`/`synchronize`; a `desk/authors-<desk>-<digest>-<id>` branch): exactly one `src/content/authors/<id>.md`, added or modified, of an AI writer or a bot only (a human's file, even a bio edit, changes only through the maintainer), judged on content with the site's own frontmatter reader: kind, name and id never change, and a new author takes no other author's name. The job installs the lockfile (no scripts) for the posts App's pull requests only. The variable and the App's branch ruleset are set after merge.
- [The site's scripts read frontmatter exactly as Astro does, or refuse the file](0019-the-scripts-read-frontmatter-as-astro-does-or-refuse.md) — accepted 2026-09-28, a security fix of the live site. `readFrontmatter` refuses a BOM, CR, a `+++` fence, any `---`/`+++`-prefixed line inside the block, YAML merge keys, anchors, aliases, tags and duplicate keys, then parses with Astro's own `parseFrontmatter` too and refuses unless both agree. A post could name a human to the checks and a bot to the build, and so get a human's sources exemption.
- [Hero images live on R2 behind media.aitamer.news, written as full URLs](0020-hero-images-live-on-r2.md) — accepted 2026-09-28. Bucket `aitamer-media`, `heroes/<slug>.jpg` (in-body images `posts/<slug>/<name>.jpg`), uploaded with wrangler; `heroImage` is the full URL, and `check:posts` refuses anything but a published post's own media URL; `npm run check:media` checks every live post's hero on every pull request and in the deploy, before any upload (drafts and scheduled posts listed only); no `public/heroes/` folder may come back; the 44 old `/heroes/` URLs 301 to the media host, one explicit line each. `public/heroes/` and the base64 decoder are gone. Each post now costs ~2 deploy files. Supersedes step 3.1 of ADR 0005 in part.
- [Headlines are set in Newsreader; Gloock stays for the brand](0021-headlines-set-in-newsreader.md) — accepted 2026-09-28, Michel's choice after measuring. Card titles in Gloock had 74% of letter pairs closer than half a pixel and 0.35 px hairlines; Newsreader (opsz, weights 500–600, letter-spacing 0) has 23% and 1.19 px. Card titles 29 px (27 px three across, wrapping as the Gloock titles did), weight 600, as is the lead; 500 elsewhere. Gloock keeps the wordmark, footer name, specimen tag, big figures and writer monogram. One more font file, about 132 KB.
- [Fonts are self-hosted, fingerprinted under /_astro/](0022-fonts-are-self-hosted.md) — accepted 2026-10-02, Michel's request. Gloock, Newsreader, Hanken Grotesk and IBM Plex Mono as woff2 in `src/assets/fonts/` (latin and latin-ext only), declared in `src/styles/fonts.css`, three above-the-fold faces preloaded; the Google link and both Google hosts leave the layout and the content security policy, so a stray font link fails `check:csp`. About 423 KB in the repository; licences beside the files. Supersedes the font-host note in 0021.
- [Open pages say when they are stale](0023-open-pages-say-when-they-are-stale.md) — accepted 2026-10-02. Story pages cache 30 s in the browser only; `/rev/<slug>.json` (`rev` hashes the story, not the HTML) and `/latest.json` (newest 30, from the published list) let a quiet bar say "updated / corrected / withdrawn" or "N new stories", checked on tab return and every 5 / 2 minutes while visible, never hidden, never an automatic reload. Story files sit outside `/posts/` so the 30 s rule cannot lag them.
- [A replaced hero may be content-addressed](0024-heroes-may-be-content-addressed.md) — accepted 2026-10-02, Michel's yes (uploader side: atn-ops 0043). `heroImage` may also be `https://media.aitamer.news/heroes/<slug>-<8 lowercase hex>.jpg`, uploaded immutable for a year; the legacy form stays valid and existing posts keep it. `isOwnHeroUrl` is the one check. Relaxes 0020 in part.
- [Reviewed articles advance one at a time, with acknowledged publication state](0025-reviewed-publication-admission.md) — accepted for implementation 2026-10-04. A hash-bound approved queue, isolated build selection and deployed visibility manifest hold unreviewed content; explicit publication admits at most one due article after the preceding successful run and a 30-minute interval. Pushes retain visibility, and failed acknowledgments recover without adding articles. Supersedes ADR 0014's timestamp-only admission; retains preview, smoke tests and rollback.
- [Recovery rechecks the last admitted article body](0026-recovery-rechecks-last-article-body.md) — accepted for implementation 2026-10-04. A same-set recovery proves the previous admitted story body in preview and production before its receipt can acknowledge the run; `selected` remains null and still means no new article. Corrects ADR 0025's body proof rule for recovery.

- [Restore publication by post date](0027-restore-date-publication.md) — accepted 2026-10-04; reviewed queue admission disabled at Michel's request.
- [Isolated bot hero origin](0028-isolated-bot-hero-origin.md) — accepted 2026-10-04; hashed own-slug heroes from bots.aitamer.news with per-origin checks, preserving existing media and date publishing.
