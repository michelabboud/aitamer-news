## Measured encoding and finalizer amendment

Prototype q90 generated a Grok720px derivative of91276bytes, larger than the existing960px WebP77306bytes. Calibration q84 fromJPEG produced65180bytes withSSIM0.974556; six q84JPEG variants had minimumSSIM0.965364. Re-encoding the existing WebP lost more detail. Use q84JPEG plus a narrow build finalizer, rather than a fixed quality assumption or manual exception registry.

Run after Astro writes assets, before Pagefind/CSP. Inspect only owned HeroImage pictures that contain local generated candidates and the existing rawWebP candidate. Admit each derivative only if actual dimensions match its descriptor/aspect, SSIM against the resizedJPEG is at least0.95, and encoded bytes are strictly below the existingWebP. Otherwise remove only that candidate from the generated source's srcset, retain its originalWebP andJPEG, and record why. Leave generated files intact. Targeted attribute-offset editing preserves every other HTML byte, including reader text and inline scripts. Run on every cold/warm build; malformed/unavailable evidence fails closed for the derivative, not the original image. First iteration may qualify every candidate rather than introducing a second cache. Use existing parse5, ffmpeg/ffprobe and Node; no new dependency. Bound concurrency, source body/pixel size, subprocess runtime and network waits. Record admitted/excluded counts and reasons for review and measurement.

## Production integration correction I1

The full production suite rejected one legitimate Markdown body image because global image.remotePatterns also activated Astro's in-body image markers. Keep that guard unchanged. A public Satteri processor wrapper clears only Markdown/MDX shared image permissions while retaining the real processor/name/options/features. Serializable aitamerRemoteImagePolicy=passthrough-v1 invalidates old content/incremental caches. The global allow-list remains for explicit HeroImage transforms. Local imports and unowned body-image URLs remain refused.

The first full-library build optimized342pairs and logged many metadata failures; sequential reprobes of failed URLs succeeded. Add a shared six-probe semaphore with at most three attempts/backoff outside permits, caching the whole per-URL promise. Do not timeout-release a non-abortable native probe. Coverage improvement must be measured in a new independent cold-cache run; do not assert the burst hypothesis as proven before that result.
