# Prepare responsive images locally

Threat sketch: production static site; preserve approved image quality, JPEG fallback, publishing permissions and media credentials. Local preparation is trusted operator work; checked catalog changes require an ordinary code PR, never producer content admission. Public media bytes are untrusted until digest/size/MIME checks pass. Uploads use existing bucket-scoped credentials privately, create-only, without overwriting or deleting any object. No credential enters the repository or workflow.

Michel authorized this change after deployment repeatedly installed FFmpeg and reran local image qualification. Prepare and qualify variants locally once. Publish content-addressed variants on the existing media host, then check in their source/variant SHA256, dimensions, bytes and quality measurements. Routine builds select only catalogued variants, verify the current remote bytes without decoding/re-encoding, and retain original WebP/JPEG sources for new posts without prepared variants. New article publication must not depend on a local preparation service.

Implementation: strict catalog/planner and tests; reuse the existing passed local receipts and verify staged files before create-only upload/public readback; default HeroImage uses catalog without Astro transformation or remote metadata probing. Keep the old full preparation pipeline as an explicit local command. Split FFmpeg integration tests from routine site tests without hiding skips; preserve image-specific owner-approval decoding. Keep contract, media, link, CSP, secrets and numbering deployment guards. Mirror relevant source into the private template, run full local image tests plus a no-FFmpeg production build, independently review, then normal checked PR merge and production acceptance.

Owners: root integration/catalog preparation/uploader/docs; scoped worker routine test/workflow split; independent scoped catalog implementation/review. Dependencies unchanged. Existing Authors/home-feed PR324 is already merged and its deployment remains separate.
