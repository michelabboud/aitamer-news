**Manus 2.0** is **available now** on the **web, desktop, and mobile**—framed by Manus as a new architecture and product set, not a minor version bump ([Manus blog](https://manus.im/blog/introducing-manus-2-0)).

The release centers on **Cascade** (in-house agent harness), a purchasable **Cloud Computer**, event-triggered **Automations**, **Manus Studio** upgrades (Video Editor with Alchemy, Game Dev with multiplayer), and a separate **Cue** personal-agents app still in **early access**.

## Cascade

**Cascade** is Manus’s latest agent harness: it keeps a project light at the start and brings specialized capabilities only when the work needs them, so a brief, page, video, and automation stay one connected project ([Manus blog](https://manus.im/blog/introducing-manus-2-0)).

In one tested configuration, Manus says Cascade used **23.2% fewer tokens**, finished tasks in **28.2% less time**, and cost **32% less** than the previous system. Treat those percentages as **vendor one-config marketing**, not independently verified benches.

## Cloud Computer and Automations

Some projects need their own place—a multiplayer game server that stays up, or an automation that runs around the clock. Manus now lets you **purchase a Cloud Computer**: a dedicated environment for those workloads. The announce does **not** publish dollar prices or plan SKUs here; this write-up invents none ([Manus blog](https://manus.im/blog/introducing-manus-2-0)).

**Automations** move past schedule-only runs. Work can start when something happens in a connected service—Manus names a new email, a change in ad performance, a calendar event, a Slack message, or a Notion update—set up from a single prompt.

## Manus Studio: Video Editor and Game Dev

The desktop app upgrades to **Manus Studio**, a shared people-and-AI workspace. This release adds professional environments for video and games alongside everyday docs, sheets, PDFs, slides, websites, and code.

**Video Editor** hands you a **timeline** with separable clips, images, text, motion graphics, and audio so you can swap, edit, and export—or hand the cut back to Manus for another pass. **Alchemy mode** acts as an AI creative director that uses video and code generation together. That is a **Studio editing surface**, not a new foundation video-model launch.

**Game Dev** starts from a playable template; the Edit panel lets you run the game, manage assets, edit code, and change movement, art, and scenes. Multiplayer setup, as Manus describes it: **Configure → Multiplayer → Select Cloud Computer → Buy one**.

## Cue early access (not the same as Manus 2.0 “available now”)

**Cue** is a **standalone** app for personal agents on phone and desktop, built on the same infrastructure as Manus. Each agent gets its own **email**, **phone number**, **wallet**, and **computer**; agents can take calls and leave a summary, and several agents can hand work off in a group chat ([Manus blog](https://manus.im/blog/introducing-manus-2-0)).

Cue is **early access**, free with an invite code—start with **`MEETCUE`** (limited, first-come, first-served). Manus says Cue is on web, desktop, and mobile, with **iOS coming soon after App Store review**. Do not treat Cue EA as the same “available now” GA framing as Manus 2.0.

## Related surfaces (keep separate)

This is a **Manus platform** generation bump—Cascade, Cloud Computer, Automations, Studio, Cue—not a consumer personal-agent product like Muse, not shared workplace Grok teammates (Team Bots), and not an agent-UI protocol story.

Remote Control / Computer Use also appears on the primary: phone voice command into an authorized desktop session with a visible workspace on approved files, browser, and apps. Keep that within Manus’s authorized-session framing ([Manus blog](https://manus.im/blog/introducing-manus-2-0)).

## Who should care

Builders already on Manus who want the new harness, event automations, Studio video/game tools, or a purchasable Cloud Computer should start at the [Manus 2.0 announce](https://manus.im/blog/introducing-manus-2-0). Anyone chasing personal agents should treat **Cue** as invite-gated early access (`MEETCUE`), separate from Manus 2.0’s available-now surfaces.
