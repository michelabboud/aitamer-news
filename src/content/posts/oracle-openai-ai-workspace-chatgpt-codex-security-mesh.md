At its AI World conference, Oracle [announced](https://www.oracle.com/news/announcement/ai-world-oracle-reinvents-enterprise-computing-for-the-ai-era-with-openai-2026-10-27/) a set of products built with OpenAI. On [its own page](https://openai.com/index/oracle-apps-in-chatgpt), OpenAI says Oracle "is developing" the main one, so read this as a roadmap.

## The four pieces

- **Oracle AI Workspace**: plugins in ChatGPT that let employees look things up, run approved workflows and take actions in Oracle systems. Oracle says it is "designed to connect" Fusion Applications, NetSuite, Oracle AI Database and OCI.
- **Oracle AI Security Mesh**: "a managed service that uses OpenAI cyber models" to find and fix vulnerabilities across OCI, other clouds and on-premises systems. Customers set where testing is authorized and its scope, while Oracle runs the safeguards.
- **Oracle App Composer**: build internal apps with **Codex**, while Oracle deploys and runs them on OCI. It also supports **APEXlang**, a new Oracle technology meant to avoid "opaque application code".
- **Oracle AI SMB Bundle**: a free-to-start package with "$12,000 in Oracle cloud credits each year", plus ChatGPT Business, Codex, AI Workspace, App Composer and NetSuite QuickStart.

## Buying OpenAI through Oracle

Oracle is also a big OpenAI customer. OpenAI says "Oracle reported 130,000 active ChatGPT users and more than 95,000 active Codex users" inside the company. And US Oracle customers can now buy the OpenAI API, Codex and ChatGPT Work through Oracle Marketplace, using existing procurement and "eligible Oracle Universal Credits".

## What's missing

Dates and prices. Oracle's release ends with its standard disclaimer that this outlines "general product direction" and "is not a commitment to deliver any material, code, or functionality". If you run Oracle apps, the Marketplace billing is the part that matters now. Everything else is worth a pilot when it ships.
