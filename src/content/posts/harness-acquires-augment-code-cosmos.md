Harness and Augment Code both say part of Augment's coding-agent stack is moving to Harness. The posts are dated 8 October 2026. [Augment CEO Matt McClernan](https://www.augmentcode.com/blog/augment-code-next-chapter) writes that Cosmos, the Auggie CLI, the Code Context Engine, and related technology are joining Harness. [Harness CEO Jyoti Bansal](https://www.harness.io/blog/harness-acquires-augment-code-cosmos) writes that Harness acquired those select assets and that the team behind them will join Harness. Neither post states a price.

The Harness headline is broader than that sentence. It reads "Harness acquires Augment Code to advance the Autonomous SDLC." The body, and Augment's post, say select assets. McClernan writes, "We've agreed to sell these select assets because Harness's integrated platform delivers these capabilities to customers more effectively than building them independently." He says the team behind these products is moving to Harness. He does not say what is left of Augment Code besides those assets. Bansal says Harness is investing in the products, the technology, and the people who built them.

## What they mean by a software factory

Augment uses "software factory" for orchestrating AI-written code across a whole system: generation is the easy part, and testing, verifying, and deploying it is the bottleneck. Harness uses it for a repeatable loop. When a ticket is assigned or a bug is reported, Harness Cosmos can coordinate agents to plan the change, write code and tests, open a pull request, and respond to feedback, so the team can decide whether to merge. Bansal says work can start from ticket updates, pull requests, schedules, and webhooks.

Cosmos becomes the Harness Cosmos Software Factory Agent. Bansal's role for it is engineering work from idea to code. Other Harness agents take that code to production. It joins the Harness Autonomous SDLC Platform beside the agents he names for software delivery, security testing, runtime protection, and cost management. The [product page](https://www.harness.io/products/cosmos-software-factory-agent) uses that name and says Cosmos takes work from idea to merge-ready code.

The announcement names four prebuilt Experts: PR Author, Deep Reviewer, Risk Analyzer, and Verifier. The product page also lists Ticket Dispatcher, Project Builder, Pair Reviewer, Feedback Triager, and Cosmos Analyst. Harness says the factory also includes execution environments, model routing, the Code Context Engine, tool integrations, shared memory, and budget controls. Connecting that context engine to Harness's Software Delivery Knowledge Graph is described as a next step, so testing and production findings can inform a change before it is written.

## What is not spelled out

The two posts, the product page, and the [Augment changelog](https://www.augmentcode.com/changelog) do not detail the transition for existing customers. They do not say what happens to current Augment plans, the IDE extensions, or today's Auggie CLI users. Harness does say customers can adopt the Cosmos agent, keep their preferred coding tools, or use both, and that Cosmos is available now. That is a choice of tools, not a schedule for current Augment subscriptions.

## Practical takeaway

Both companies state the same asset list and the same team move. The Harness headline says "acquires Augment Code." The paragraphs say select assets. No price is disclosed. Customers waiting on a plan, plugin, or CLI transition will not find it in these announcements.
