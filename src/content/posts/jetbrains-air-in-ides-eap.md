JetBrains launched an **Early Access Program** for **Air in JetBrains IDEs**—available now as a **Marketplace** plugin or natively in **2026.3 EAP** builds ([blog](https://blog.jetbrains.com/ai/2026/10/air-in-ides-eap/)). This is early access, not generally available. The product surface is the **IDE plugin / 2026.3 EAP conduit**—not the March 2026 **standalone Air** ADE preview.

## What shipped

**Install:** Marketplace plugin (usable in **2026.2** IDEs per overview) or **2026.3 EAP** builds; no separate plugin license. Overview excludes **Android Studio** ([overview](https://www.jetbrains.com/help/air-ides/air-overview.html), [Marketplace](https://plugins.jetbrains.com/plugin/33314-air)).

**Conduit, not a provider:** The Air plugin ships with **no agents installed**. Bring agents you already use—FAQ out of the box: **Codex**, Gemini, **GitHub Copilot**, **Claude Agent**, **Junie**, plus many others via **ACP**. JetBrains AI subscription is supported but **not required** to use your own agents ([blog](https://blog.jetbrains.com/ai/2026/10/air-in-ides-eap/), [help](https://www.jetbrains.com/help/idea/air-in-jetbrains-ides.html)).

**Multi-agent sessions:** Agentic-first UX for **multiple agents in parallel**—sessions as editor tabs, terminal UI, or graphical chat; Agent Sessions tool window for progress, changed files, commits, and cost; temporary worktrees for isolation ([blog](https://blog.jetbrains.com/ai/2026/10/air-in-ides-eap/)).

IDE review tools (diffs, inspections) and built-in skills (debugging, profiling, DB exploration, semantic search) are available to supported agents as JetBrains states.

## Availability

- **Early access, not generally available** — under active development; expect UI changes and rough edges ([help](https://www.jetbrains.com/help/idea/air-in-jetbrains-ides.html)).
- **Cloud runs** currently need org **AI seats** / JetBrains AI for cloud; local BYO agents do not require that subscription ([blog](https://blog.jetbrains.com/ai/2026/10/air-in-ides-eap/)).
- **Junie Lite free\*** after JetBrains Account sign-in — “terms and available models may change.”
- Mobile follow-along for cloud: “coming soon.”

## Related products

This is Air **in JetBrains IDEs**, not the March 2026 **standalone Air** public-preview ADE (`air.dev` / agentic DE built around agents rather than as an IntelliJ plugin) ([March post](https://blog.jetbrains.com/air/2026/03/air-launches-as-public-preview-a-new-wave-of-dev-tooling-built-on-26-years-of-experience/)). Same brand family; different surface.

## Who should care

IntelliJ-family users who want parallel agent sessions without being tied to a JetBrains-only model should start at the [Air in IDEs EAP post](https://blog.jetbrains.com/ai/2026/10/air-in-ides-eap/).
